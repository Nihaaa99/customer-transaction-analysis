# Customer & Transaction Analysis

SQL portfolio exercise using synthetic customer and transaction data.

## Business questions
- How many transactions are completed, pending or failed?
- Which customers have the highest completed transaction value?
- How do payment channels compare?
- Which customers spend above the average?

## Files
- `customers.csv` — fictional customer records
- `transactions.csv` — fictional transaction records
- `analysis.sql` — SQL queries for transaction status, customer spend, payment channels and above-average spend

## Run
Import the CSV files into SQLite/MySQL as `customers` and `transactions`, then execute `analysis.sql`. Dates and records are fictional sample data created for this portfolio. Query findings should be added after running and checking the scripts.

## Status
Practice portfolio project. Dataset and queries are provided; results have not yet been independently validated or interpreted.
